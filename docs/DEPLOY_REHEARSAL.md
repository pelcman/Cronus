# デプロイリハーサル・チェックリスト

最終目標(固定公開IPで仲間内プレイ)に向けた実地確認の手順書です。
**Stage 1(LAN)→ Stage 2(公開IP)**の順で進めます。前提のセットアップ手順は
[SERVER_SETUP.md](SERVER_SETUP.md) を参照してください。

---

## Stage 1: LANリハーサル(同一ネットワークの2台目PC)

### 準備
- [ ] サーバーPCのLAN IPを確認: `ipconfig`(例: `192.168.1.10`)
- [ ] `.env` を編集: `CRONUS_HOST=192.168.1.10`
- [ ] サーバー起動 → ログの `advertised to clients as 192.168.1.10` を確認
- [ ] Windowsファイアウォールで受信許可: TCP **8484, 7575, 7576, 7577**
      (チャンネル数を変えている場合は 7575..+N と、その次のポイントショップ用ポート)
- [ ] 2台目PC: JMS v186クライアント + WZパッチ適用 + EmuClientの接続先を
      サーバーPCのLAN IPに設定

### 確認項目(2台目PCの実クライアントで)
- [ ] ログイン画面 → 新規ID/パスワードで自動アカウント作成
- [ ] キャラクター作成 → ゲーム入場
- [ ] マップ移動・モブ討伐・ドロップ拾得・**再ログイン**(クラッシュしないこと)
- [ ] NPC会話(ショップ・倉庫・美容室・タクシー)
- [ ] クエスト受諾 → 進行 → 完了 → 連鎖(電球アイコンのNPCで)
- [ ] リアクター(箱・草花)破壊 → ドロップ
- [ ] チャンネル変更、ポイントショップ入退場
- [ ] **2アカウント同時接続**: 相互に姿が見える・チャット・耳打ち・パーティ・トレード
- [ ] サーバー再起動 → 両キャラクターが残っていること(SQLite永続化)

### 問題が出たら
- サーバー側ログ(`CRONUS_DEBUG=1` で全パケットhex記録)を保存
- 症状と時刻をメモ(ログの行と突き合わせるため)

---

## Stage 2: 公開IPリハーサル(外部の協力者1名)

### 準備
- [ ] 契約回線の公開IPを確認(https://ifconfig.me)。CGNAT の場合はポート開放不可
      なので、VPS 中継や Tailscale 等の代替を検討
- [ ] ルーターでポートフォワード: TCP **8484, 7575, 7576, 7577** → サーバーPC
- [ ] `.env`: `CRONUS_HOST=<公開IP>`(またはDDNSホスト名)
- [ ] (推奨)`CRONUS_AUTO_REGISTER` は最初の全員登録が済んだら `0` に
      (以後は既存アカウントのみ=簡易許可リスト)
- [ ] `cronus.db` のバックアップを取ってから開始(SERVER_SETUP.md「Backing up」)

### 確認項目
- [ ] 外部回線(スマホテザリング等でも可)からログイン〜入場
- [ ] Stage 1 の確認項目を一通り
- [ ] 30分以上の連続プレイでの切断・ラグの体感
- [ ] ホスト側: メモリ使用量が安定していること(タスクマネージャーで Cronus.Server.Host)

### セキュリティ最低限
- [x] パスワードはBCryptハッシュ保存(実装済み)
- [ ] 登録完了後 `CRONUS_AUTO_REGISTER=0`
- [ ] `cronus.db` の定期バックアップ(停止してコピー)
- [ ] 遊ばない時間帯はサーバーを止める運用でも可

---

## 結果の記録

リハーサルで見つかった問題・ドキュメントの不足は AGENTS.md のバックログに追記して
ください。ログ(`server_run.log` 相当)とあわせて報告があれば、パケットレベルで
原因を追跡できます。
