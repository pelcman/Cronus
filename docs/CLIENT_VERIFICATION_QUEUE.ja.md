# 実クライアント検証キュー（あなた宛の作業リスト）

このファイルは「テストと bot は緑だが、まだ実クライアントで通し確認していない」機能を積んでおく場所です。
手が空いたときに **develop を 1 回ビルドして起動**（`run-server.bat`）し、下の項目を上から順に潰してください。
1 つのビルドに全部入っているので、まとめて確認できます。

- 確認できたら `[ ]` を `[x]` に。壊れていた項目は「時刻・マップ・直前の操作」を 1 行メモしてください。
  サーバーのパケットダンプ（`CRONUS_DEBUG=1`）とログから、こちらで `fix/<項目>` ブランチを切って直します。
- **このキューが空になるまで `main` への stable タグ（stable-3 以降）は切りません。** 実機で確認できていない
  ものを「安定版」に載せないためです。develop は統合用なので、緑の実装は先に入れて構いません。
- 起動は `run-server.bat`（World / Login / Channel の 3 タブ）、停止は `stop-server.bat`。

前提: JMS v186.1 クライアント + EmuClient で `127.0.0.1:8484` に接続、GM キャラ（TunaYukke）。
