# ゲーム内コマンド

> English version: **[COMMANDS.md](COMMANDS.md)**

チャットで **`/`** から始まる発言はサーバー側でコマンドとして処理され、**他のプレイヤーには
表示されません**。応答は自分のチャット欄に自分の発言として返ってきます。存在しないコマンドは
`unknown command: <名前>` と返します。

> **権限システムは未実装です。** 接続している全プレイヤーが全コマンドを使えます。身内サーバー
> なら問題ありませんが、公開範囲を広げる際は注意してください。

`CRONUS_DB` を設定しない限りキャラクターはメモリ上にのみ存在するため、コマンドで付与した
アイテム等はサーバー再起動で消えます([SERVER_SETUP.md](SERVER_SETUP.md) 参照)。

## 詳細

### `/map <マップID>`
指定 ID のマップへワープします(スポーンポータル 0)。wz データのないマップでも動作します
(マップの描画はクライアント側の wz が行うため)。変な場所に出てしまったら
`/map 100000000`(ヘネシス)で戻れます。

```
/map 100010000     ← 低レベル狩場(カタツムリ・キノコ)
```

### `/warp <プレイヤー名>`
オンラインの別プレイヤーがいるマップへワープします。名前の大文字小文字は区別しません。
相手がこのチャンネルにいない(または自分自身)場合は `'<名前>' is not online` と返します。

### `/meso <n>`
メルを `n` 追加します(0〜2,147,483,647 にクランプ)。負数を渡すと減ります。

### `/heal`
HP と MP を全回復します。パーティーメンバーには HP バーの回復が見えます。

### `/job <職業ID>`
職業 ID を設定します。ビッグバン以前の主な ID(2次職 = 基本+10、3次/4次職はさらに +1/+2。
例: ファイター 110 → クルセイダー 111 → ヒーロー 112):

| 基本 | 1次職 | 2次職 |
|---|---|---|
| 0 | 初心者 | — |
| 100 | 剣士 | 110 ファイター / 120 ページ / 130 スピアマン |
| 200 | 魔法使い | 210 ウィザード(火・毒) / 220 ウィザード(氷・雷) / 230 クレリック |
| 300 | 弓使い | 310 ハンター / 320 クロスボウマン |
| 400 | 盗賊 | 410 アサシン / 420 シーフ |
| 500 | 海賊 | 510 インファイター / 520 ガンスリンガー |

### `/level <n>`
レベルを上げる方向では**本物のレベルアップ処理**が走ります — 職業ごとの範囲で HP/MP が成長
(成長パッシブも反映)し、AP/SP も付与されます。下げる方向はレベル値のみ変更(ステータス維持)。
EXP は 0 にリセットされ、パーティーウィンドウも更新されます。

### `/hp <n>` · `/mp <n>` · `/maxhp <n>` · `/maxmp <n>`
現在値・最大値の HP/MP を**設定**します。現在値は最大値でクランプされます(`/hp 0` で死亡 —
死亡・復活のテストに便利)。最大値は 1〜30000 にクランプされ、現在値も一緒に切り詰められます。
HP の変化はパーティーメンバーにも見えます。

### `/str <n>` · `/dex <n>` · `/int <n>` · `/luk <n>`
基本ステータスを直接**設定**します(4〜32767)。ダメージや命中などの派生値はクライアントが
新しいステータスから再計算します。

### `/ap <n>` · `/sp <n>`
AP / SP を `n` 追加します(差分指定。結果は 0 以上にクランプ)。SP はスキルウィンドウ
(デフォルト `K` キー)で振れます。スキルレベルは wz の最大レベルでキャップされます。

### `/fame <n>`
人気度を `n` に**設定**します(追加ではありません)。−30000〜30000 にクランプ。

### `/item <アイテムID> [個数]`
指定アイテムを `個数`(省略時 1)だけインベントリに生成します。消費アイテム等は wz の
`slotMax` までスタックし、装備は 1 個 1 スロットで wz の基本性能(攻撃力・防御力・強化可能
回数など)が付くため、そのまま装備スロットへドラッグして装備できます。

```
/item 2000000 30   ← 赤い薬 30 個(HP +50)
/item 1302000      ← 剣(攻撃力 17・強化可能回数 7)
/item 2030004      ← ヘネシス帰還の書(使うとワープ)
/item 2012000      ← 攻撃力の薬(物理攻撃 +8 を 5 分間)
```

### `/shop <ショップID>`
ショップテーブル(`CRONUS_SHOPS`)から指定 ID の NPC ショップを開きます。購入はメル払い、
売却はアイテムの wz 価格で買い取られます。ショップ `11100` は薬ショップです。
(マップ上の商人 NPC をクリックしてもそのショップが開きます — コマンドは直接開くための
ショートカットです。)

### `/storage`
倉庫(アカウント内の全キャラクター共有)を開きます。預け入れは一律 100 メルの手数料、
引き出しは無料です。現状はメモリ上のみ — サーバー再起動で消えます。

### `/save`
キャラクターを即時保存します(定期オートセーブと切断時の保存もあります)。`saved` と返します。

### `/players`(別名 `/online`)
このチャンネルにオンラインの全プレイヤー名を一覧します。

### `/guildcreate <名前>`
`名前` のギルドを作成し、自分がギルドマスター(ランク 1)になります。無料でどこでも使える
身内サーバー向けショートカットです。クライアント本来の作成フロー(オルビスのギルド本部、
マップ `200000301`、5,000,000 メル)も動作します。勧誘・加入・脱退・除名・ランク・エンブレム
(本部 + 1,500 万メル)・お知らせはゲーム内のギルドウィンドウ(G キー)から操作します。
ギルドマスターが脱退するとギルドは解散します。

### `/maxskills`
現在の職業の習得チェーン(初心者 → 1次 → 現在の転職段階まで)にある全スキルを wz の最大
レベルにします。`/job` や転職直後に便利です。

### `/notice <メッセージ>`
**現在のマップにいる全員**へ、青文字のシステムお知らせとして放送します。

### `/pos`
自分の `(x, y)` 座標とマップ ID を返します。NPC・ポータルスクリプトを書くときに便利です
([SCRIPTING.md](SCRIPTING.md) 参照)。

### `/help`
全コマンドを 1 行で一覧します。

## クライアント標準のコマンド

クライアント自身のスラッシュコマンドはサーバーのコマンドとは独立して動作します。特に
ささやきウィンドウの **`/find <名前>`**(所在確認)とささやき本体は、サーバーの
ウィスパーハンドラーが応答します。
