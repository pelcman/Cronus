# ゲーム内コマンド

> English version: **[COMMANDS.md](COMMANDS.md)**

チャットで **`/`** から始まる発言はサーバー側でコマンドとして処理され、**他のプレイヤーには
表示されません**。応答は自分のチャット欄に自分の発言として返ってきます。出力は 1 行ごとに
1 パケットで送るため、複数行の出力(`/help` や `/status`)もクライアントで読みやすく改行されます。

コマンド層が面倒を見てくれること:

- **`/help`** はカテゴリ別に 1 コマンド 1 行で全体を表示し、**`/help <コマンド名>`** は
  そのコマンドの書式・説明・別名を表示します。
- **引数を間違えると、そのコマンドの正しい書式が返ります。**
  `/item apple` → `使い方: /item <アイテムID> [個数]`
- **打ち間違いは一番近いコマンドを提案します。**
  `/healx` → `不明なコマンド: /healx — もしかして /heal ?`

全コマンドの定義は 1 つのテーブル
([`ChannelHandler.CommandTable.cs`](../src/Cronus.Server.Channel/ChannelHandler.CommandTable.cs))
にまとまっており、`/help`・引数エラーの応答・このドキュメントが食い違わないようになっています。

> **権限システムは未実装です。** 接続している全プレイヤーが全コマンドを使えます。身内サーバー
> なら問題ありませんが、公開範囲を広げる際は注意してください。

## クイックリファレンス

### 移動

| コマンド | 効果 |
|---|---|
| `/warp <マップID\|プレイヤー名>` | ワープ。数値ならマップ ID、それ以外はそのプレイヤーのいるマップ |
| `/dbgwarp` | ワープコンソールを開く。地域 → エリア → マップ を選ぶだけ(ID 不要) |
| `/pos` | 自分の座標とマップ ID を表示 |

### キャラクター

| コマンド | 効果 |
|---|---|
| `/status` | ステータス一覧を表示 |
| `/status <項目> <n>` | ステータスを変更(項目は下表) |
| `/heal` | HP/MP 全回復 |
| `/maxskills` | 現在の職業が覚えられるスキルを全てマスターにする |
| `/gender [m\|f]` | 性別を切替(または指定)。チャンネル再入場で見た目に反映 |
| `/beauty` | スタイルコンソール: 全髪型・髪色・整形・目の色・肌をウィンドウで選択 |

### アイテム

| コマンド | 効果 |
|---|---|
| `/item <アイテムID> [個数]` | アイテムをインベントリに生成 |
| `/drop <アイテムID\|0> [個数]` | 足元にドロップを生成(`0` はメル塊) |
| `/shop` | デバッグショップ: ジャンル → ページ を選ぶと全アイテムが 1 メル |

| `/clear book` | モンスターブックを消去(登録済みのカードが再びドロップするようになる) |

## 詳細

### `/warp <マップID|プレイヤー名>`
数値を渡すとそのマップへワープします(スポーンポータル 0)。数値以外はオンラインプレイヤー名
として扱い、その相手のいるマップへ飛びます。名前の大文字小文字は区別しません。相手がこの
チャンネルにいない(または自分自身)場合は `'<名前>' はオンラインではありません` と返します。
マップ ID は wz データのないマップでも動作します(描画はクライアント側の wz が行うため)。変な
場所に出てしまったら `/warp 100000000`(ヘネシス)で戻れます。

```
/warp 100010000     ← 低レベル狩場(カタツムリ・キノコ)
/warp Alice         ← Alice のところへ
```

### `/dbgwarp`
ID を覚えなくて済むワープコンソールを開きます。**地域 → エリア → マップ** の 3 段で、
まずゲーム内の名前テーブルにある 10 地域(メイプルアイランド・ビクトリアアイランド・
オシリア大陸 …)、次にその中のエリア(ヘネシス・オルビス …)、最後にそのエリアのマップを
ID 付きで表示します。20 件を超えるリストにはページ選択が挟まります。

表示されるのは**実際にフィールドデータがあるマップだけ**です。名前テーブルには約 5,500 マップ
が載っていますが、v186 のデータでデータがあるのは約 3,270 だけで、それ以外へ飛ぶと
クライアントは描くものが無くなってしまいます。`CRONUS_WZ` が必要です
(`String/Map.img.xml` と `Map/` を読みます)。未設定の場合はカタログ未ロードと返します。

### `/status`
引数なしでステータス一覧を表示します。

```
── Hero ── Lv.42 job 112 exp 0
HP 2400/2400   MP 800/800
STR 250  DEX 40  INT 4  LUK 25
AP 0  SP 3  fame 12  meso 1500000
変更するには /status <項目> <値>
```

### `/status <項目> <n>`
ステータスを 1 つ変更します。各項目はそのままコマンド名としても使えます
(`/hp 500` ≡ `/status hp 500`)。

| 項目 | 効果 |
|---|---|
| `level` | レベルを**設定**(1〜200。EXP は 0 にリセット) |
| `job` | 職業 ID を設定(下表) |
| `exp` | EXP を**設定** |
| `hp` · `mp` | 現在 HP / MP を**設定**(最大値でクランプ) |
| `maxhp` · `maxmp` | 最大 HP / MP を**設定**(1〜30000。現在値も一緒に下がる) |
| `str` `dex` `int` `luk` | 基本ステータスを**設定**(4〜32767) |
| `ap` · `sp` | AP / SP を `n` **加算**(0 未満にはならない) |
| `fame` | 人気度を**設定**(−30000〜30000) |
| `meso` | メルを `n` **加算**(負数で減算。0〜2,147,483,647 でクランプ) |

実質的な処理が入るのは `level` です。**上げる**場合は実際のレベルアップ処理が走り、職業の
成長レンジ(成長パッシブ込み)で HP/MP が増え、AP/SP も狩りで上げたときと同じように付きます。
**下げる**場合は数値だけを設定し、ステータスはそのままです。どちらも EXP は 0 にリセットされ、
パーティウィンドウが更新されます。HP/MP の変更はパーティの HP バーにも反映されます。

ビッグバン前の主な職業 ID(2 次職 = 基本+10、3 次/4 次は +1/+2。例: ファイター 110 →
クルセイダー 111 → ヒーロー 112):

| 基本 | 1 次職 | 2 次職 |
|---|---|---|
| 0 | 初心者 | — |
| 100 | 剣士 | 110 ファイター / 120 ペイジ / 130 スピアマン |
| 200 | 魔法使い | 210 ウィザード(火・毒) / 220 ウィザード(氷・雷) / 230 クレリック |
| 300 | 弓使い | 310 ハンター / 320 クロスボウマン |
| 400 | 盗賊 | 410 アサシン / 420 シーフ |
| 500 | 海賊 | 510 インファイター / 520 ガンスリンガー |

### `/heal`
HP と MP を全回復します。パーティメンバーの HP バーにも反映されます。

### `/maxskills`
現在の職業の習得チェーン(初心者 → 1 次職 → 各転職先)のスキルを全て wz の最大レベルにします。
`/status job` や転職の直後に便利です。

### `/gender [m|f]`
`/gender` で切替、`/gender m` / `/gender f`(`male`/`female`、`0`/`1`、`男`/`女` も可)で指定。
性別は入場時の CharacterData に含まれるため、見た目を描き直すために同一チャンネルへの
再入場を挟みます。**アカウント**側の性別も追従します
(`GameConstants.GenderCommandChangesAccount`)。ポイントショップの品揃えはアカウント性別で
絞られるので、切替を反映するには再ログインしてください。

### `/beauty`
スタイルコンソールを開きます。wz データにある**全ての**髪型・髪色・整形・目の色・肌を、
アバタープレビュー付きのページで選べます(ID 指定は不要)。`CRONUS_WZ` が必要です。

### `/item <アイテムID> [個数]`
アイテムを `個数`(既定 1)だけインベントリに生成します。束アイテムは wz の `slotMax` まで
スタックし、装備は 1 スロットずつ、wz の基本ステータス(攻撃力・防御力・アップグレード可能
回数 …)付きで入るので、そのまま装備欄にドラッグできます。

```
/item 2000000 30   ← 赤いポーション 30 個(HP +50)
/item 1302000      ← ソード(攻撃力 17、アップグレード 7 回)
/item 2030004      ← ヘネシス帰還スクロール(使うとワープ)
/item 2012000      ← 攻撃の秘薬(5 分間 攻撃力 +8)
```

### `/drop <アイテムID|0> [個数]`
足元に実際の地面ドロップを生成します。ドロップ → 取得の流れをまるごと試せるので、
クライアントや bot の検証に便利です。`0` を指定すると `個数` メルのメル塊になります。

### `/shop` · `/shop <ショップID>`
ID なしで**デバッグショップ**が開きます。ジャンル(帽子・武器・消費 …)→ ページを選ぶと、
そのページの全アイテムが 1 メルで購入できます。陳列されるのは実際にデータがあるアイテムだけ
です — wz の文字列テーブルには v186 クライアントが描画できない ID が約 134 個含まれており、
それを並べるとクライアントが落ちます。

ID を渡すとショップテーブル(`CRONUS_SHOPS`)のその NPC ショップを開きます。メルで購入でき、
売却は wz の価格で買い取られます。ショップ `11100` はポーション屋です(マップ上の店員 NPC を
クリックしても同じショップが開きます。コマンドは直接開くための近道です)。

### `/storage`
倉庫を開きます(アカウント内の全キャラクターで共有)。預け入れは一律 100 メル、引き出しは
無料です。

### `/clear <inv [タブ] | quest <id> | book>`
- **`inv`** インベントリを空にします。全 5 タブ、または `/clear inv 2` で 1 タブだけ。所持
  アイテムのみで、装備中の装備は残ります。1 スロットずつ削除を送るので、その場で反映されます。
- **`quest <id>`** 指定クエストを進行中・完了の両方の記録から消し、クエストの流れを再実行
  できるようにします(主にスクリプト/bot 検証用)。
- **`book`** モンスターブックを消去します。カードを 1 度登録するとその Mob はカードを落とさなく
  なる(`GameConstants.MonsterCardStopDropCount`)ので、再びドロップさせたいときに使います。

### `/notice <メッセージ>` · `/notice all <メッセージ>`
青文字のシステムお知らせを放送します。通常は**現在のマップ**のみ、`all` を付けると
全チャンネル・全マップに放送します。

### `/players`
オンラインのプレイヤー名を一覧表示します。

### `/guildcreate <名前>`
自分をマスター(ランク 1)としてギルドを作成します — 無料で、どこでも実行できます。
これはプライベートサーバー用の近道で、クライアント本来の作成フロー(オルビスのギルド本部
マップ `200000301`)も動作し、こちらは本来の 500 万メルが必要です。招待・加入・脱退・追放・
ランク・エンブレム(本部 + 1500 万メル)・お知らせは全てゲーム内のギルドウィンドウ(G キー)
から行えます。マスターが脱退するとギルドは解散します。

### `/save`
キャラクターを即時保存します(定期保存と切断時の保存もあります)。`saved` と返します。

### `/pos`
自分の `(x, y)` 座標とマップ ID を返します。NPC/ポータルスクリプトを書くときに便利です
([SCRIPTING.md](SCRIPTING.md) 参照)。

### `/help [コマンド名]`
`/help` は全コマンドをカテゴリ別に、1 行 1 コマンドで書式付きで表示します。
`/help <コマンド名>` は 1 つの詳細(カテゴリ・書式・説明・別名)を表示します。別名でも引ける
ので、`/help map` は `/warp` の項目を表示します。

## クライアント内蔵のコマンド

クライアント自身のスラッシュコマンドは、サーバーのコマンド群とは独立してそのまま動作します。
特に便利なのはウィスパー UI の **`/find <名前>`**(居場所検索)とウィスパーそのもので、
どちらもサーバーのウィスパーハンドラが応答します。
